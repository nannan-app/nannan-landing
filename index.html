04 · 隐私设计Privacy by design

日记应该是
一件私事。 A diary should be
a private thing.

从第一行代码开始，喃喃就在守护这件事。 Murmur was built from the first line of code to keep it that way.

100% 本地存储100% local storage

没有云端、没有服务器、不需要注册账号。数据只存在你的电脑上。随时导出加密备份。No cloud, no servers, no accounts. Data lives on your machine — and nowhere else. Export an encrypted backup any time.

AES-256-GCM + Argon2AES-256-GCM + Argon2

每条日记逐字段加密。图片在磁盘上加密，文件名哈希。连缩略图都在加密数据库里。Every entry encrypted at the field level. Images encrypted on disk with hashed filenames. Even thumbnails live inside the encrypted DB.

合理否认性Plausible deniability

错密码打开伪装日记，对密码进入真实空间。两个完全隔离的世界。Wrong password opens a decoy. Right password opens the real one. Two fully isolated worlds, no cross-talk.

恢复码Recovery code

忘了密码？用恢复码取回。无需邮箱、手机、第三方。两把独立的锁，守护同一把主密钥。Forgot your password? Use the recovery code. No email, no phone, no third party. Two independent locks on one master key.
